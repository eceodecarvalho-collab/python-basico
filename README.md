# Python básico

Primeros programas en **Python** del máster (Tema 1: *Variables, tipos de datos y operaciones básicas*),
escritos y ejecutados con **IDLE** (Python 3.9).

## Ejercicios

| Archivo | Qué hace |
|---|---|
| `01-bienvenida.py` | Guarda un mensaje en una variable, pide tu nombre con `input()` y te saluda con un f-string. |

## Lo que se practica

- Variables y cadenas de texto (`str`)
- `print()` para mostrar datos
- `input()` para leer datos del teclado
- f-strings para combinar texto y variables
- Leer errores como `NameError` (usar una variable antes de crearla)

## Cómo ejecutarlos

```bash
python3 01-bienvenida.py
```

O ábrelo en IDLE (**File > Open**) y pulsa **F5** (**Run > Run Module**).
